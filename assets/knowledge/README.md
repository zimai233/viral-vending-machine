# 知识库

> 对标分析 / 复盘结论 / 选题判断的落盘位置。跨任务决策有据可依。
> 每次对标分析、发布复盘后，把结论写入这里（按日期/主题分文件）。
> 建议格式：日期 → 主题 → 发现 → 结论 → 下一步。

## 使用约定

1. **对标分析后**：把「这个博主的爆款逻辑、可借鉴点」追加到 `对标/<博主名>.md`
2. **发布复盘后**：把「数据表现、为什么爆/扑、下次改进」追加到 `复盘/<日期>.md`
3. **选题判断**：把「这个方向为什么值得做」记录到 `选题/<方向>.md`

## 目录

```
knowledge/
├── 对标/     # 每位对标博主的深度分析（比 frameworks.md 更细、含复盘结论）
├── 复盘/     # 每次发布后的数据复盘
└── 选题/     # 选题方向的判断依据
```
