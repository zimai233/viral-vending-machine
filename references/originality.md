# 防洗稿自检清单

> 核心原则：学选题、学角度、学结构、学节奏 → 原创表达。
> 不复制：原句、专有表达、金句、案例细节。

## 生成前必读
1. **逐句对照**：与原文逐句比对，连续 6+ 字相同或语义完全一致的句子必须改写。
2. **相似度阈值**：与单条原文整篇相似度 > 30% 判为洗稿需重写；与多篇平均 < 20%。
3. **表达替换**：用自己的话重述观点；用词、语序、例子必须与原文不同。
4. **角度验证**：同一选题，切入角度/观点/结构若与原文雷同，换一个角度。
5. **事实与案例**：不照搬原文数据、测评结论、个人故事；用自己的素材或通用事实。
6. **AI 化残留**：避免"首先/其次/总而言之"等套路连接词。

## 相似度检测（工具）
运行：`python scripts/similarity.py --draft <生成文案文件> --refs <原文文件或目录>`
输出：逐条相似度 + 命中片段。任何一条 >30% 或出现 6+ 字连续命中，必须改写后重测。

## 改写策略（相似度过高时）
1. 换角度：同一主题换一个切入视角。
2. 换结构：清单→故事，或故事→对比。
3. 换表达：同义改写、口语化、加自己的经历。
4. 换案例：用自己的素材替代原文案例。
5. 重测，最多 2 轮；仍超标则标注"高风险，需人工再改"。
