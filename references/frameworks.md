## 皇阿玛（恋爱关系 · 教女生识人派）

> 抖音号 41470367 | 粉丝 184.7万 | 数据：近3个月 top20（3.4万~34万赞）

### 选题方向（6类）

1. **男生秘密/心理解读**（数据最强）：「恋爱中男生绝对不会告诉你的秘密」系列
   - 逻辑：站女生视角揭男生的底，满足"他到底怎么想"的窥探欲。
2. **识人筛选/排雷**：「什么样的男生一看就不靠谱」「什么样的男生绝对不能成为你的男朋友」
   - 逻辑：给女生安全感 + 可操作避坑清单。
3. **恋爱经营方法**：「想要谈好恋爱必须要做的5件事」「如何做一个合格的男朋友」
   - 逻辑：数字清单 + 经验总结，收藏属性强。
4. **行为边界科普**：「女生觉得很正常男生觉得很暧昧的事」「有男朋友之后有哪些事绝对不能做」
   - 逻辑：男女思维差异造成的误判，共鸣强、易引发讨论。
5. **质量恋爱观/金句**：「我不会爱你一万年 但是我会反复爱上你一万次」
   - 逻辑：一句话击中，情绪价值拉满，转发率高。
6. **互动内容（读私信）**：拉近距离，维持亲切人设。

### 标题框架

- 反问式：「什么样的男生一看就不靠谱？」
- 揭秘式：「恋爱中男生绝对不会告诉你的秘密」
- 边界式：「女生觉得很正常，男生觉得很暧昧的事」
- 结果式：「这几种方式开始的恋爱，都不会有好结果」
- 金句式：「我不会爱你一万年，但会反复爱上你一万次」

### 结构套路

- 开头 3 秒抛核心结论或反差问题 → 中段 3-5 个生活化场景点 → 结尾金句 + 引导互动。
- 固定标签：#小郭的碎碎念 #女生必看 + 垂类标签 + 节日借势。

## 林有感（恋爱认知 · 清醒理性派）

> 抖音号 Linyougan | 数据：近3个月全部 8 条（1.4万~50万赞）

### 选题方向（6类）

1. **爱情本质的清醒认知**（50万赞最强）：「爱是尽可能不包容」「爱从来不是在最好的日子里被证明的」
   - 逻辑：反常识金句 + "原来如此"顿悟感。
2. **结婚识人技巧**：「趁还有冲动」「快速识人技巧」
   - 逻辑：可操作观察清单 + 经验智慧感。
3. **关系里的自我边界**：「先有自己 再有我们」
   - 逻辑：戳中"在关系里失去自我"的普遍痛点。
4. **男生心理话术**：「男生不会主动跟女生提的几个话题」
   - 逻辑：揭秘式（与皇阿玛同逻辑，但语气更平静）。
5. **情绪与生活哲思**：「你不是每个时候都能蒸出个不错的粽子」
   - 逻辑：生活小事 + 哲理升华，亲切有共鸣。
6. **聊天式碎碎念**：「介入 干预 创造自己的生活」（停车艺术家感悟）
   - 逻辑：日常琐事讲出人生感，拉近距离。

### 标题框架

- 反常识断言：「爱是尽可能不包容」
- 结论金句：「爱从来不是在最好的日子里被证明的」
- 生活比喻：「你不是每个时候都能蒸出个不错的粽子」
- 二元结构：「先有自己 再有我们」

### 口播风格（重要仿写参考）

- 开头直接抛观点/设问，不铺垫。
- 口语化长句 + 生活化举例（蒸粽子、停车），理论落地到日常。
- 语气平静、笃定、有经历感，不煽情不喊口号。
- 结构：观点 → 拆解 → 生活例子 → 回到观点升华。
- 收尾给耐人寻味的小结，不硬求互动。

## 通用借鉴（对「我」的启示）

- **选题**：学「识人/排雷/揭秘/反常识金句/生活哲理」框架，换成 01 年职场新人的视角。
- **结构**：数字清单 / 男女思维差异 / 金句收尾 / 生活小事升华，都可借用。
- **红线**：只学选题与框架，不复制原句；用简体普通话（林有感是繁体台湾腔，不学腔调）。
- **人设底色**：保留「同龄人把关系想明白」的真诚与成长感，不装老成、不教女生、不贩卖焦虑。
