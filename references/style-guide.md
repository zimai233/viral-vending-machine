# 文案表达形式规范（从对标案例提炼）

> 生成任何文案前必读。这是从两位对标博主（皇阿玛 / 林有感）的 28 条高赞口播中提炼的表达规律。
> **输出的文案必须全面套用这些形式，再叠加「我」的人设视角。**

---

## 一、六大内容形式（选题框架）

对标案例里的高赞内容，全部属于以下 6 类形式。生成时先选形式，再套结构。

| 形式 | 核心逻辑 | 案例示例 | 适用场景 |
|---|---|---|---|
| **揭秘式** | 讲「对方不会说出口的真话」 | 「恋爱中男生绝对不会告诉你的秘密」 | 窥探欲、反差感最强，数据最好 |
| **避坑式** | 教「什么样的不能要 / 千万别做」 | 「什么样的男生一看就不靠谱」 | 给安全感 + 可操作清单 |
| **清单式** | 教「怎么做 / 怎么判断」 | 「想要谈好恋爱必须要做的5件事」 | 干货、收藏属性强 |
| **金句式** | 一句话击中情绪的观点 | 「爱是尽可能不包容」 | 转发率最高、情绪价值拉满 |
| **反差式** | 讲「男女认知差异造成的误解」 | 「女生觉得很正常男生觉得很暧昧的事」 | 共鸣强、评论区互动高 |
| **观点式** | 一个清醒认知的完整论述 | 「先有自己 再有我们」 | 深度感、人设立得住 |

## 二、开头的 5 种钩子写法

| 钩子类型 | 写法模式 | 案例 |
|---|---|---|
| **预告式** | 「接下来要讲/说的话，你听了可能会（吵架/扎心/生气），但我必须说」 | 「你听了肯定得吵架，但我还是得告诉你」 |
| **站队式** | 「我作为男生，跟你说句实话」 | 「我是男生，替兄弟们把话说明白」 |
| **痛点设问** | 「为什么你（越主动，他越躲）？」 | 直击目标人群的日常困惑 |
| **结论先行** | 一句话抛出反常识观点 | 「爱不靠包容」「先有自己 再有我们」 |
| **场景代入** | 从一个小故事/日常细节切入 | 「今天早上我蒸粽子锅烧干了……」 |

**规则**：前 3 秒必须出现钩子，不允许铺垫、客套、自我介绍式开场。

## 三、正文结构的 3 种套路

### 套路1：列举展开（揭秘式/避坑式/清单式的主干）
```
第一/第二/第三…（数字列举，通常 3-6 点）
每点固定节奏：抛结论 → 给生活化场景/例子 → 落一句狠话或提醒
```

**每点的展开公式（从皇阿玛提炼）**：
1. **抛结论**：「第一，他回你消息慢，真的不是忙。」
2. **给场景**：「你看他打游戏能熬到凌晨两点，就知道没时间三个字有多假。」
3. **落点**：「想找你的人，洗个澡都能擦着手回你。」（用具体动作制造画面感）

### 套路2：观点递进（金句式/观点式的主干）
```
先抛核心观点 → 拆解 2-3 层（是什么/为什么/怎么办）→ 用生活例子落地 → 升华回观点
```

### 套路3：故事隐喻（林有感特色）
```
一个小事/日常观察（蒸粽子、停车）→ 提炼出普世道理 → 展开论述 → 收尾升华
```

## 四、语言特征（必须模仿的"味"）

1. **口语流水句**：一句能讲完的不用标点切断，保持"说话感"而非"作文感"。
   - 例：「如果你谈恋谈到某时间节点觉得自己特别特别累不想谈了……」
2. **重复强调**：关键情绪词叠用（"特别特别累""真的真的"），制造真实感。
3. **自嘲护体**：讲狠话前先"免责"——「别骂我，我只是实话实说」「我作为男生我都知道」。
4. **反问扎心**：讲完一个点，反问对方「你能明白吗」「你自己心里没数吗」。
5. **画面感细节**：用具体动作/物品代替抽象描述（"擦着手回你"优于"很主动"）。
6. **短句收尾**：每点收在短句上（"这就是答案""醒一醒"），有力不拖沓。

## 五、结尾的 CTA 模式

| 模式 | 写法 | 效果 |
|---|---|---|
| **共鸣引导** | 「你遇到过类似的时刻吗？评论区聊聊」 | 互动 |
| **站队认同** | 「认同的点赞，让更多姐妹看见」 | 点赞传播 |
| **留白金句** | 一句耐人寻味的话收束（「先爱自己，再被爱」） | 收藏转发 |
| **悬念钩子** | 「你中过哪条？评论区告诉我，下期细讲」 | 涨粉关注 |

**规则**：CTA 不硬、不喊口号、不群发式求三连；落在「我们是一路人」而非「我很厉害」。

## 六、通用禁忌（生成时逐条自查）

- ❌ 不用「首先/其次/总而言之」等 AI 味连接词（用「第一/第二」或直接换行）。
- ❌ 不用「宝子们/家人们」营销腔。
- ❌ 不堆设计术语类比（设计师身份最多一句带过）。
- ❌ 不写空泛鸡汤（「真爱总会来」无信息量）。
- ❌ 不制造男女对立、不贩卖焦虑、不 PUA 话术。
- ✅ 每条要有「具体细节」支撑观点，拒绝空转。

## 七、输出格式要求（每条文案的交付结构）

生成时必须按以下格式交付，缺一不可：

```
【标题】（一句话，套用形式标题写法）
【形式】（揭秘式/避坑式/清单式/金句式/反差式/观点式）
【主要观点】（一句话说清这条要传达什么）
【口播脚本】（完整口语脚本，300字左右，套用上述全部规律）
【话题标签】（3-5个 #）
```

## 八、与「我」的人设叠加方式

- **视角**：全部内容 = 「我作为男生，对女生说真话」。用第一人称「我」的观察/经历切入。
- **性别立场**：站在女生一边帮她识人避坑，但保持客观（「不是所有男生都这样，但这样做大概率就是」）。
- **设计背景**：仅在自然需要时一句带过（「做设计让我看细节特别准」），不展开。
- **年轻感**：保留 01 年职场新人的真诚成长感，不装老成、不说教（区别林有感的"过来人"腔调）。
- **克制温度**：ENFJ 共情 + 不油腻，讲狠话但留温度。
