# 各平台文案规则

> 生成前先确认平台，再套用对应规则。

## 小红书
- 标题：15-30字，情绪化，可带 emoji，前3-5字抓眼球。
- 正文：口语化、分点/分段清晰，多用换行；emoji 点缀不过量。
- 话题标签：3-8 个 #，尾部添加，主标签 + 泛标签。
- 长度：300-1000 字为宜。
- 常见结构：痛点/场景开头 → 干货/清单/对比 → 体验感受 → CTA。

## 抖音
- 文案即视频 description：黄金 3 秒开头钩子（反问/冲突/结果预告）。
- 口播脚本：短句、有节奏、口头语自然；每段一个信息点。
- 结尾：明确行动指令（点赞/评论关键词/关注）。
- 话题：# 3-5 个。

## 公众号/长文
- 标题：两个方案（观点鲜明型 / 悬念好奇型）。
- 正文：结构完整，小标题分段，可讲一个完整故事或深度干货。
- 结尾：金句收束 + 引导互动 + 往期回顾。

## 通用
- 避免 AI 味连接词：首先/其次/总而言之/综上所述。
- 避免空话套话：不说"在当今时代""众所周知"。
- 一行别太长，中文 20 字内换行更易读。
